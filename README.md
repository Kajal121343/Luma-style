# Luma-style

A modern e-commerce web application built using React, Vite, Redux, and Tailwind CSS. The platform allows users to view products, filter categories, search items, manage cart and wishlist, and view detailed product information.

 **Live Demo:** https://magenta-clafoutis-e64c65.netlify.app/

---

## Features

### Dashboard

* Fixed Header with logo, cart, wishlist, search, and login
* Banner with smooth UI effects
* Product categories and dynamic product listing
* Footer with company info and contact details

### Product Browsing

* Category-based filtering 
* Search functionality for products
* Dynamic product data using Fake Store API

### Cart Functionality

* Add to cart and remove from cart
* Dynamic total price calculation
* Cart item count displayed in header
* Data stored using Local Storage

### Wishlist

* Add and remove items from wishlist
* Separate wishlist page

### Product Details Page

* Product image, name, and price


### Authentication

* Login page with username ,Email and  password validation

### UI/UX

* Responsive design for mobile, tablet, and desktop
* Clean and simple interface
* Smooth hover effects

---

## Tech Stack

* Frontend: React.js
* State Management: Redux, React-Redux, Redux-Thunk
* Routing: React Router DOM
* Styling: Tailwind CSS
* Icons: React Icons
* API: Fake Store API

---

## Development Guidelines

* Built as a Single Page Application (SPA)
* Component-based structure
* API-based dynamic data rendering
* Input validation for forms
* LocalStorage used for cart and wishlist
* Responsive UI

---

## Deployment

The application is deployed on Netlify and connected with GitHub.
